织念备忘 隐私政策

更新日期：2026-11-09 生效日期：2026-11-09 版本：v1.3

织念备忘（以下简称“本应用”）由 徐睿（以下简称“我们”）开发并运营。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全。请您在使用本应用前，仔细阅读并充分理解本《隐私政策》。

一、适用范围

本政策适用于织念备忘鸿蒙客户端。本应用不提供账号注册与登录功能，不收集您的手机号、身份证号、通讯录、地理位置等身份信息。

二、我们处理的信息及用途

  1. 笔记内容：标题、正文、标签、双链和导入文件保存在本机，用于展示、检索、导出与备份。
  2. 语音速记：主动录音后，音频保存在本机供回放。本版本没有语音转文字，文字需您自己输入。不会在未录音时采集声音，也不会上传录音。
  3. 待办与提醒：到期提醒走系统提醒代理。应用进程仍在时可以播放可听闹铃。进程内定时器不能保证进程结束后仍会响。本版本已删除静音保活。
  4. 导入与导出：系统选择器只访问您选中的文件。Word 和可携带离线包由您选择位置。旧版笔记 JSON 只在应用目录，不含待办和附件。离线包不含密钥和锁定笔记正文。
  5. 偏好设置：主题、字号、授权状态和模型地址保存在本机 Preferences。模型密钥不在其中。
  6. 可选模型补漏：默认关闭。只有系统能够禁用 HTTP 自动重定向时，主动发送才会把未锁定文字发到保存密钥时确认的 HTTPS 主机。版本不够或读不到版本时不发送。密钥放在系统 Asset Store；系统拒绝时网络补漏关闭，不改存明文。

三、系统权限说明

  1. ohos.permission.MICROPHONE：只用于录音，不用于语音转文字。
  2. ohos.permission.PUBLISH_AGENT_REMINDER：只用于待办提醒。是否生效需在设备上确认。
  3. ohos.permission.INTERNET：只用于您主动发送的模型补漏，默认关闭。
  4. 文件与图片通过系统选择器访问。
  5. 不申请定位、通讯录、通话记录、短信、IMEI，不做广告跟踪。

四、数据存储与安全

  1. 您的笔记数据存储在本机应用沙箱内（RDB 数据库与文件目录），卸载应用或清除应用数据后将被删除。
  2. 私密保险箱口令是访问控制，不是正文加密。口令以加盐哈希保存。
  3. 除您主动发送的模型补漏外，本应用没有自己的笔记服务器。设备丢失和系统备份仍有风险。

五、数据导出、备份与删除

  1. 导出：可导出 Word 和可携带离线包。旧版 JSON 只在应用目录。
  2. 系统备份：应用内备份扩展目前只写日志，不代替离线包。系统备份由系统设置控制。
  3. 删除：您可以随时删除单条笔记（进入回收站）、清空回收站，或在「收纳盒 - 关于与隐私」中清空全部本地数据。该操作不可恢复，请谨慎操作。

六、第三方共享与 SDK

  1. 本应用不接入广告、统计、推送或分析 SDK。模型补漏开启且您主动发送时，该次文字会交给您填写的服务商。
  2. 当您主动使用“分享”“预览”“拖拽到其他应用”时，相关内容将由系统分享面板或您选择的目标应用处理，请遵守目标应用的隐私政策。

七、您的权利

  1. 访问与更正：您可以在应用内随时查看、修改、导出您的笔记内容。
  2. 删除：您可以删除单条内容或清空全部本地数据。
  3. 撤回同意：您可以在「收纳盒 - 关于与隐私」中撤回隐私授权；撤回后本应用将停止后续处理并退出。
  4. 注销账号：本应用无账号体系，不涉及账号注销。

八、未成年人保护

本应用不面向不满 14 周岁的儿童单独提供服务。未成年人应在监护人指导下使用本应用；如监护人发现未成年人在未经同意的情况下使用本应用，可联系我们删除相关数据。

九、政策更新

我们可能适时更新本政策。更新后我们将在应用内提示，并在您同意后生效。

十、个人信息收集清单与第三方共享清单（双清单）

  1. 已收集个人信息清单：本应用在您使用对应功能时产生的笔记、待办、语音录音、导入附件、保险箱口令校验值与偏好设置，均仅保存在本机应用沙箱，具体种类、目的与使用场景详见应用内「收纳盒 - 关于与隐私 - 已收集个人信息清单」。
  2. 第三方共享个人信息清单：除您主动发送到自填模型主机，以及系统分享外，不向第三方出售个人信息。

十一、数据保存期限

  1. 笔记、待办、语音录音、附件等本地数据保存至您主动删除、执行「清空全部本地数据」或卸载本应用为止。
  2. 偏好设置与隐私授权状态保存至您撤销授权、清空应用数据或卸载本应用为止。
  3. 若您把模型地址填成境外主机并主动发送，该次文字会发往该主机。除此以外不会自行外发笔记。
