织念备忘 隐私政策

更新日期：2026-11-03 生效日期：2026-11-03 版本：v1.2

织念备忘（以下简称“本应用”）由 徐睿（以下简称“我们”）开发并运营。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全。请您在使用本应用前，仔细阅读并充分理解本《隐私政策》。

一、适用范围

本政策适用于织念备忘鸿蒙客户端。本应用不提供账号注册与登录功能，不收集您的手机号、身份证号、通讯录、地理位置等身份信息。

二、我们处理的信息及用途

  1. 笔记内容：您输入的标题、正文、标签、双链关系，以及导入的图片、PDF、Word 等文件。上述内容仅保存在本机应用沙箱（关系型数据库与文件目录），用于展示、检索、导出与备份，不会上传至任何服务器。
  2. 语音速记：当您主动点击“语音速记”并授权麦克风后，本应用录制音频并保存在本机应用沙箱，用于回放与转写辅助；不进行后台上传，也不会在您未主动录音时采集声音。
  3. 待办与提醒：当您为待办设置到期提醒时，本应用通过鸿蒙系统提醒代理（ReminderAgent）与本机闹铃通知在设定时间触发响铃提醒，仅传递提醒标题、时间与来源标记。
  4. 导入与导出：导入图片/文件时使用系统选择器（PhotoViewPicker/DocumentViewPicker），本应用仅访问您明确选中的文件并复制到应用沙箱；导出 Word、JSON 备份时由您选择保存位置。
  5. 偏好设置：主题、字号、隐私授权状态、新手引导状态、保险箱口令校验值等设置保存在本机 Preferences 中。

三、系统权限说明

  1. ohos.permission.MICROPHONE（麦克风）：仅用于“语音速记”录音功能，录音仅保存在本机；拒绝授权不影响文字笔记、图片/文件查看与导出等功能。
  2. ohos.permission.PUBLISH_AGENT_REMINDER（提醒代理）：仅用于待办到期响铃提醒，不读取您的日历内容。
  3. 文件与图片：通过系统选择器授权访问所选文件，不申请全量相册或存储读取权限。
  4. 本应用不申请定位、通讯录、通话记录、短信、IMEI 等权限，不进行广告跟踪。

四、数据存储与安全

  1. 您的笔记数据存储在本机应用沙箱内（RDB 数据库与文件目录），卸载应用或清除应用数据后将被删除。
  2. 私密保险箱通过本机口令进行访问控制，口令以加盐哈希方式保存，不保存明文口令；请妥善保管口令，忘记口令将无法通过本应用找回。
  3. 本应用不设远程服务器，笔记内容不会上传，因此不存在云端数据泄露风险；但请注意本机设备丢失、被他人使用或系统备份带来的风险。

五、数据导出、备份与删除

  1. 导出：您可以在笔记编辑页导出 Word，或在「收纳盒」导出 JSON 备份文件，导出内容由您自行保管。
  2. 系统备份：若您的设备开启了系统备份且允许本应用参与备份，应用数据可能随系统备份保存；您可以在系统设置中关闭。
  3. 删除：您可以随时删除单条笔记（进入回收站）、清空回收站，或在「收纳盒 - 关于与隐私」中清空全部本地数据。该操作不可恢复，请谨慎操作。

六、第三方共享与 SDK

  1. 本应用不接入第三方广告、统计、推送或分析 SDK，不会向任何第三方出售、共享您的笔记内容。
  2. 当您主动使用“分享”“预览”“拖拽到其他应用”时，相关内容将由系统分享面板或您选择的目标应用处理，请遵守目标应用的隐私政策。

七、您的权利

  1. 访问与更正：您可以在应用内随时查看、修改、导出您的笔记内容。
  2. 删除：您可以删除单条内容或清空全部本地数据。
  3. 撤回同意：您可以在「收纳盒 - 关于与隐私」中撤回隐私授权；撤回后本应用将停止后续处理并退出。
  4. 注销账号：本应用无账号体系，不涉及账号注销。

八、未成年人保护

本应用不面向不满 14 周岁的儿童单独提供服务。未成年人应在监护人指导下使用本应用；如监护人发现未成年人在未经同意的情况下使用本应用，可联系我们删除相关数据。

九、政策更新

我们可能适时更新本政策。更新后我们将在应用内提示，并在您同意后生效。

十、个人信息收集清单与第三方共享清单（双清单）

  1. 已收集个人信息清单：本应用在您使用对应功能时产生的笔记、待办、语音录音、导入附件、保险箱口令校验值与偏好设置，均仅保存在本机应用沙箱，具体种类、目的与使用场景详见应用内「收纳盒 - 关于与隐私 - 已收集个人信息清单」。
  2. 第三方共享个人信息清单：本应用未接入任何第三方 SDK，不向任何第三方出售、共享或转让您的个人信息，具体详见应用内「收纳盒 - 关于与隐私 - 第三方共享个人信息清单」。

十一、数据保存期限

  1. 笔记、待办、语音录音、附件等本地数据保存至您主动删除、执行「清空全部本地数据」或卸载本应用为止。
  2. 偏好设置与隐私授权状态保存至您撤销授权、清空应用数据或卸载本应用为止。
  3. 本应用不向境外提供您的个人信息。
